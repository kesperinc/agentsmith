# 2026-08-13 Agent Smith IDE Handover Document

본 문서는 **Agent Smith IDE (Custom Code-OSS AI Editor)** 프로젝트 개발을 타 PC 및 다른 환경에서 끊김 없이 이어서 진행할 수 있도록 빌드 이슈 극복 내역, 아키텍처 및 기동 체크리스트를 인계하는 핸드오버(인수인계) 문서입니다.

---

## 📂 1. 프로젝트 개요 & 아키텍처

본 프로젝트는 폐쇄망 및 사내 인프라에 대응하는 **데스크톱 중심의 자체 AI 에디터(IDE)** 구축을 목표로 합니다.

* **에디터 클라이언트**: Code-OSS v1.86.0 기반 빌드
* **AI 챗 패널**: `extension/agentsmith-chat` 커스텀 빌트인 익스텐션 (사이드바 웹뷰)
  * Glassmorphism 어두운 다크 테마 UI 적용
  * 마이크 음성 STT(base64 전송), 이메일 OTP 검증 로그인 모달, AI 모델 선택 드롭다운 탑재 완료
* **로컬 백엔드 서버**: Python FastAPI (coding-agent/src/main.py)
  * smtplib 연동 OTP 메일 발송 및 세션 검증
  * JSON Base64 오디오 바이너리 포맷 수신 및 모의 STT 텍스트 피딩 API

## 🛠️ 2. 핵심 빌드 트러블슈팅 및 우회 기법 (중요)

타 PC에서 빌드를 구성할 때 반드시 발생하는 윈도우 환경 특화 빌드 에러들과 해결법입니다.

### ① MSBuild 스펙터(Spectre) 라이브러리 누락 에러 (`MSB8040`)
* **현상**: C++ Native 패키지 컴파일 시 스펙터 완화 라이브러리가 없다며 빌드가 터짐.
* **원인**: `@vscode/policy-watcher` 및 `@vscode/spdlog` 의 `binding.gyp` 에 `"SpectreMitigation": "Spectre"` 가 하드코딩되어 상위 props를 무시함.
* **해결법**: 각 패키지의 `binding.gyp`에서 `"SpectreMitigation": "Spectre"`를 **`"SpectreMitigation": "false"`** 로 패치함.

### ② Node.js v24 자식 프로세스 스폰 에러 (`EINVAL`)
* **현상**: 윈도우 환경에서 빌드 훅 기동 시 `spawn EINVAL`로 쉘 프로세스가 즉시 터짐.
* **원인**: Node.js 최신 v24 버전이 윈도우 cmd.exe 호출 시 호환성을 타기 때문.
* **해결법**: 모든 실행 스크립트 실행 시 내장 런타임인 **Node.js v18.17.1**(`build/node/`)로 PATH 환경변수 오버라이딩을 강제함.

### ③ Gulp 전체 컴파일 메모리 부족 현상 (행/Hung 발생)
* **현상**: `yarn watch`나 `yarn compile` 기동 시 `Starting compilation...`에서 무한 멈춤.
* **원인**: `package.json`에 `max-old-space-size=4095` (4GB) 제한이 걸려 있어 타입스크립트 컴파일러가 메모리 고갈로 뻗음.
* **해결법**: 
  1. 타입 체크를 건너뛰고 SWC를 활용해 초고속 빌드를 해주는 **`transpile-client`** 태스크를 가동하여 1분 만에 `out/` 폴더를 빌드함.
  2. 메모리 용량을 **`8192` (8GB)**로 확장 공급하여 빌드를 가동함.

## 🚀 3. 타 PC 작업 전환 시 5초 기동 가이드 (런북)

다른 PC에서 프로젝트 소스를 Pull 받은 뒤 에디터와 백엔드를 즉시 기동하는 명령어 세트입니다.

### [1] 백엔드 서버 기동 (Python FastAPI)
```cmd
cd coding-agent
.venv\Scripts\activate
python src/main.py
```
*(FastAPI 서버가 Port 5000에서 정상 구동됨)*

### [2] 의존성 설치 및 초고속 트랜스파일 (내장 Node v18 적용)
```cmd
cd vscode

:: 1. 락 방지를 위해 컴파일 훅을 무시하고 패키지만 다운로드
cmd.exe /c "set PATH=C:\dev\antigravity-workspace\aifullstack\agentsmith\build\node;%PATH% && yarn install --ignore-scripts"

:: 2. @vscode/policy-watcher 및 @vscode/spdlog의 binding.gyp 속 SpectreMitigation을 false로 편집
:: 3. 수동 패키지 후속 설치 및 초고속 SWC 트랜스파일 수행 (8GB 메모리 할당)
cmd.exe /c "set PATH=C:\dev\antigravity-workspace\aifullstack\agentsmith\build\node;%PATH% && node --max-old-space-size=8192 ./node_modules/gulp/bin/gulp.js transpile-client"
```

### [3] 에디터 클라이언트 기동
```cmd
cmd.exe /c "set PATH=C:\dev\antigravity-workspace\aifullstack\agentsmith\build\node;%PATH% && .\scripts\code.bat"
```
*(화면에 에디터 창이 팝업되며 정상 시연 가능 상태 진입)*
