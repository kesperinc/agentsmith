3. 서버 메모리(RAM) & Local NVMe SSD 추천 사양 및 Ceph 대치 솔루션

System RAM & NVMe SSD 사양

• RAM: 512GB ~ 1TB DDR5 ECC Registered (SNO Control Plane 32GB+ & vLLM KV Cache & Vector DB 상주)
• NVMe SSD: 4x 7.68TB Enterprise U.2/U.3 (Raw 30.7TB)
  - 1.92TB RAID1 Mirror: OS Boot & OpenShift etcd
  - 10TB: vLLM / HuggingFace 모델 가중치 초고속 캐시

Ceph 대체 로컬/공유 스토리지 솔루션

• OpenShift LVM Storage (topolvm): 단일 서버 로컬 NVMe를 K8s 고성능 CSI PV로 변환하여 Vector DB 및 DB에 초저지연 I/O 공급.

5. Red Hat OpenShift AI (RHOAI) vLLM & KServe 배포 YAML 스크립트 모음

A. Cohere Command vLLM ServingRuntime (`vllm-cohere-runtime.yaml`)

apiVersion: serving.kserve.io/v1alpha1
kind: ServingRuntime
metadata:
  name: vllm-cohere-runtime
  namespace: rhoai-cohere-poc
spec:
  supportedModelFormats:
    - name: vLLM
  containers:
    - name: kserve-container
      image: quay.io/modh/vllm:rhoai-2.14
      command: ["python3", "-m", "vllm.entrypoints.openai.api_server"]
      args:
        - "--model=/mnt/models/cohere-command-r"
        - "--tensor-parallel-size=2"
        - "--quantization=fp8"
        - "--max-model-len=16384"
        - "--gpu-memory-utilization=0.90"
      resources:
        limits: { nvidia.com/gpu: "2", memory: "64Gi" }
        requests: { nvidia.com/gpu: "2", memory: "32Gi" }

B. Qwen2.5-Coder-32B vLLM ServingRuntime (`qwen-coder-runtime.yaml`)

apiVersion: serving.kserve.io/v1alpha1
kind: ServingRuntime
metadata:
  name: qwen25-coder-runtime
  namespace: rhoai-coding-agent
spec:
  supportedModelFormats:
    - name: vLLM
  containers:
    - name: kserve-container
      image: quay.io/modh/vllm:rhoai-2.14

        - "--model=Qwen/Qwen2.5-Coder-32B-Instruct"

        - "--enable-prefix-caching"
