## 1. 개요 및 인수인계 목적

본 문서는 현재 PC에서 완료된 **Agent Smith Phase 0 (바이너리 SOG 및 장애 해결), Phase 1 (Windows 에디터 브랜딩/인스톨러), Phase 2 (Antigravity 아티팩트/챗 패널/Mem0/Graphify/가드레일)**의 개발 결과물을 바탕으로, **내일 다른 PC(신규 개발 환경 또는 타 장비)에서 즉시 작업을 이어받아 개발, 빌드, 시연 및 배포를 진행할 수 있도록 작성된 1-Click 작업 연속성 런북(Runbook)**입니다.

## 4. 🚀 신규 PC 1-Click 빠른 작업 재개 절차 (Step-by-Step Runbook)

새로운 PC에서 터미널(PowerShell)을 열고 아래의 7단계를 순서대로 실행하십시오.

### Step 1: 저장소 복제 및 브랜치 최신화

```powershell
# 1. 대상 디렉터리로 이동 후 저장소 복제
git clone https://github.com/kesperinc/agentsmith.git c:\dev\antigravity-workspace\agentsmith
cd c:\dev\antigravity-workspace\agentsmith

# 2. 작업 브랜치 체크아웃 및 최신화
git checkout feature/setup-git-guardrails
git pull origin feature/setup-git-guardrails

# 3. Windows 한글 깨짐 방지 및 UTF-8 강제 설정
git config --global core.quotepath false
git config --global gui.encoding utf-8
git config --global i18n.commitencoding utf-8
```

---

### Step 2: 독립 환경설정 파일 (`.env`) 생성 및 API 키 등록

```powershell
# 1. 템플릿 복사
copy .env.example .env

# 2. .env 파일을 에디터로 열어 보유 중인 AI 모델 API 키 입력
# (GEMINI_API_KEY, OPENROUTER_API_KEY, ANTHROPIC_API_KEY 등)
notepad .env
```

> **`.env` 주요 설정 항목**:
> ```properties
> AGENTSMITH_WORKSPACE_ROOT=c:\dev\antigravity-workspace\agentsmith
> HOST=127.0.0.1
> PORT=5000
> GEMINI_API_KEY=your_gemini_api_key_here
> OPENROUTER_API_KEY=your_openrouter_api_key_here
> ANTHROPIC_API_KEY=your_anthropic_api_key_here
> OPENAI_API_KEY=your_openai_api_key_here
> ```

---

### Step 3: `uv` 기반 Python 가상환경 생성 및 의존성 설치

```powershell
# 1. uv 가상환경 (.venv) 생성 (AGENTS.md 규칙 14)
uv venv .venv

# 2. coding-agent 백엔드 필수 패키지 고속 설치
uv pip install -r coding-agent/requirements.txt --python .venv\Scripts\python.exe
```

---

### Step 4: Mem0 장기 기억 & 지식 저장소 자동 초기화

```powershell
# Mem0 SQLite 및 Qdrant 컬렉션 셋업 스크립트 실행
powershell -ExecutionPolicy Bypass -File .\2026-08-14_setup_mem0.ps1
```

---

### Step 5: 백엔드 및 코어 엔진 무결성 통합 진단 (5초 검증)

```powershell
# 7대 핵심 백엔드 엔드포인트 무결성 자동 검증 (100% PASS 확인)
.venv\Scripts\python.exe scripts/test_backend_integrity.py
```

---

### Step 6: 포터블 데스크톱 번들 및 C# Native 인스톨러 빌드

```powershell
# 1. 사전 환경 검사
.venv\Scripts\python.exe scripts/verify_desktop_bundle.py --pre-check

# 2. 데스크톱 포터블 번들 패키징 (검은 화면 방지 Unpacked 모듈 및 더미 asar 자동 주입)
.venv\Scripts\python.exe scripts/package_desktop_dist.py

# 3. C# Native 단일 실행 설치 파일 빌드
.venv\Scripts\python.exe scripts/build_desktop_installer.py

# 4. 사후 산출물 5초 무결성 검증
.venv\Scripts\python.exe scripts/verify_desktop_bundle.py --verify-dist
```

---

### Step 7: 데스크톱 IDE 실행 및 시연 확인

```powershell
# 1. 포터블 번들 즉시 실행
.\dist\agentsmith-desktop-v1.0.0\run_agentsmith_desktop.bat

# 또는 루트 디렉터리의 무소음 런처 실행
wscript agentsmith.vbs
```

## 6. 트러블슈팅 및 장애 대처 지침 (Troubleshooting Guide)

| 증상 | 원인 | 즉시 해결 방법 |
|---|---|---|
| **에디터 실행 시 검은 화면 (Black Screen)** | `out/` 번들 손상 또는 asar 후킹 문제 | `.venv\Scripts\python.exe scripts/package_desktop_dist.py`를 재실행하여 Unpacked 번들 및 28바이트 더미 asar 복원 |
| **`corrupt installation` 경고창 발생** | VS Code 코어 바이너리 체크섬 경고 | VSCodium 커스텀 빌드 특성에 따른 알림이므로 정상 동작에 영향 없음 (`Don't Show Again` 클릭) |
| **백엔드 연결 실패 (포트 충돌)** | 5000번 포트가 이미 점유됨 | `Get-Process python \| Stop-Process -Force` 실행 후 IDE 재기동 |
| **C# csc.exe 컴파일러 미발견** | Roslyn 경로 환경변수 미등록 | `scripts/build_desktop_installer.py`가 `C:\Windows\Microsoft.NET\Framework64\` 내의 csc.exe를 자동 탐색하여 빌드함 |
