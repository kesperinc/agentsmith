## 3. 새로운 PC에서 작업 재개 절차 (New PC Quick-Start Runbook)

새로운 PC에 자리를 잡은 후 아래 **5단계 명령**을 순서대로 실행하면 3분 이내에 100% 동기화된 환경에서 개발을 시작할 수 있습니다.

### Step 1: 저장소 클론 및 브랜치 이동

```powershell
# 1. 저장소 클론
git clone https://github.com/kesperinc/agentsmith.git agentsmith
cd agentsmith

# 2. 작업 브랜치 체크아웃
git checkout feature/setup-git-guardrails

# 3. UTF-8 인코딩 가드레일 설정 (Windows 필수)
git config --global core.quotepath false
git config --global gui.encoding utf-8
git config --global i18n.commitencoding utf-8
```

### Step 2: Python 가상환경 (`.venv`) 구축 및 의존성 라이브러리 설치

```powershell
# 1. uv를 이용한 파이썬 가상환경 생성 (규칙 14 준수)
uv venv .venv

# 2. coding-agent 백엔드 필수 패키지 28종 일괄 설치
uv pip install -r coding-agent/requirements.txt --python .venv\Scripts\python.exe
```

### Step 3: Mem0 & Qdrant 메모리DB 자동 초기화

```powershell
# Mem0 자동 셋업 스크립트 실행 (Bun mem0ai 패키지 설치 및 .agentsmith/mem0_config.json 생성)
powershell -ExecutionPolicy Bypass -File 2026-08-14_setup_mem0.ps1
```

### Step 4: 환경 변수 (`.env`) 생성

프로젝트 루트 디렉터리에 `.env` 파일을 새로 생성하고 아래 내용을 기입합니다:

```env
# Agent Smith API Key 바인딩
GEMINI_API_KEY=your_gemini_api_key_here
# 또는
GOOGLE_API_KEY=your_google_api_key_here

# 백엔드 서버 설정
PORT=5000
HOST=127.0.0.1
PYTHONUTF8=1
PYTHONIOENCODING=utf-8
```

### Step 5: 애플리케이션 실행 및 검증

```cmd
:: 원터치 데스크톱 버전 구동 (Port 5000 백엔드 자동 점검 포함)
run_agent_smith.bat
```

## 6. 트러블슈팅 매뉴얼 (Troubleshooting)

1. **포트 5000번 점유 오류 발생 시**:
   ```powershell
   netstat -ano | findstr :5000
   taskkill /PID <PID> /F
   ```
2. **한글 출력 깨짐 발생 시**:
   - `PYTHONUTF8=1` 환경변수 설정 및 CMD/PowerShell 코덱 UTF-8 (`chcp 65001`) 여부 점검.
3. **가상환경 중복 생성 금지**:
   - 새 PC에서 `.venv`를 한 번 생성한 후에는 추가 패키지 설치 시 `uv pip install <package> --python .venv\Scripts\python.exe`를 사용합니다.
