## 🛠️ 수정 상세 내역 & 조치 사항

### 1. MSBuild Spectre Mitigation 속성 상속의 한계와 Gyp 패치
* **현상**: 프로젝트 루트나 `vscode/` 디렉터리에 `Directory.Build.props`를 정의했음에도 불구하고, `@vscode/policy-watcher` 및 `@vscode/spdlog` 네이티브 모듈 빌드 시 지속적으로 MSB8040 스펙터 라이브러리 부재 오류가 발생함.
* **원인**: `binding.gyp` 파일 내에 `"SpectreMitigation": "Spectre"`가 명시적으로 하드코딩 선언되어 있어 상위 디렉터리 props 속성을 강제로 무력화(Override)하고 덮어썼기 때문.
* **조치**: 각각의 `binding.gyp` 내 설정을 `"false"` 로 직접 변환해 주어, MSBuild 컴파일 단계에서 완화 라이브러리를 요구하지 않도록 조치함.

### 2. yarn install 시 롤백 방지 (Ignore-Scripts + Manual Compile)
* **현상**: `yarn install` 실행 시 의존성 패키지가 원본 tarball 아카이브로부터 새로 추출되면서 기껏 수정한 `binding.gyp` 파일이 롤백 소실되는 순환 오류 발생.
* **원인**: yarn의 설치 라이프사이클 상 `Linking` 단계 이후 원본을 복원한 뒤 `postinstall` 훅을 실행하기 때문.
* **조치**: 
  1. `yarn install --ignore-scripts` 옵션을 주어 네이티브 훅 컴파일 시도 없이 의존성 패키지(예: `ternary-stream` 등)만을 100% 무오류 안전 설치.
  2. 추출 완료된 `binding.gyp` 파일을 타겟팅하여 수동 패치 적용.
  3. 내장 Node.js v18 런타임 환경에서 `node build/npm/postinstall.js` 를 직접 가동하여 전체 네이티브 컴파일 링킹 완료.
