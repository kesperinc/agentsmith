# /narration — Virtual Voice Service

`@내레이션` 에이전트가 대본을 목소리로 변환할 때 사용하는 스킬입니다. PD용 지시어와 이모지 등을 자동으로 필터링하여 순수 나레이션만을 추출합니다.

## Available Skills

| 스킬 | 설명 |보이스 타입 |
|-------|-------------|-------------|
| `/김박사` | 중후하고 신뢰감 있는 남성 목소리로 낭독 | `ko-KR-InJoonNeural` |
| `/소율` | 지적이고 명료한 여성 목소리로 낭독 | `ko-KR-SunHiNeural` |

## Usage Examples

**1. 김박사 목소리로 강독 대본 합성**
`@내레이션 /김박사 #ep02.md "이 대본을 웅장한 느낌으로 읽어줘"`

**2. 소율 목소리로 쇼츠 요약본 합성**
`@내레이션 /소율 #ep02_shorts.md "깔끔하고 빠르게 읽어줘"`

## Workflow

1. **대본 수령**: `#파일명` 형태로 전달된 마크다운 파일을 로드합니다.
2. **살균(Sanitization)**: PD용 콘티(화면, 자막 지시어), 이모지, 해시태그를 자동 제거합니다.
3. **음성 합성(TTS)**: 지정된 페르소나(김박사/소율)에 맞춰 `audio_engine.py`를 실행합니다.
4. **결과 배송**: 생성된 `.wav`와 `.srt` 파일을 `data/outputs/` 내 관련 폴더에 배치하고 보고합니다.

## Key Conventions

- 나레이션에 포함될 문장은 반드시 `**화자**: "대사"` 형식을 유지해야 합니다.
- `##`로 시작하는 헤더는 절대 읽지 않습니다.
- 괄호 `(...)` 안의 지시어는 무시됩니다.
